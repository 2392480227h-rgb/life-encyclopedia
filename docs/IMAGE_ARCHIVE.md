# 🖼️ 梗图原图档案说明

## 当前方案

网站不会把 940 件展品的网络图片一次性全部复制进仓库，而是在用户看到展品或打开详情时，按需从 Wikimedia Commons 检索图片。

匹配成功后：
- 卡片显示图片预览
- 点击图片可打开原始文件 URL
- 详情页显示许可信息与作者（若文件页提供）
- 同时保留 Wikimedia Commons 文件页
- 没有自动匹配时，提供 Commons 图片搜索入口

这样可以避免把版权状态不明的网络图片整包复制到仓库。

## 为什么先用 Wikimedia Commons

Commons 的文件页通常会提供：
- 原始文件
- 文件尺寸与 MIME 类型
- 作者/来源
- 许可证
- 文件历史
- 原始文件页面

例如 Touch grass.jpg 文件页明确给出了 4,080 × 3,072 的原始文件，并标注 CC BY-SA 4.0；This Is Fine (meme).png 文件页也提供了原始文件和许可信息。

## 后续扩充方向

后续可以继续加入：
1. Wikimedia Commons
2. 明确许可的独立站图片
3. 原始 meme 页面索引
4. 本地合法素材包
5. 人工审核后的“镇馆原图”

原则：能确认再分发许可的素材才适合直接放进仓库；版权状态不明的素材保留来源，不冒充本站拥有版权。

## 技术说明

前端使用 Wikimedia Commons API：
- namespace 6：文件
- 搜索结果限制为 1 条
- 请求 imageinfo 的原图 URL、缩略图 URL、MIME、尺寸和扩展元数据
- 使用 IntersectionObserver 懒加载，避免首页一次请求 940 张图片
